# Overall Event-Based Evaluation

This directory contains the materials used to reproduce the overall event-based performance evaluation reported in IJIES Manuscript 20264753.

The overall evaluation combines the event-level results from the distraction, drowsiness/yawning, and simulated medical-emergency experiments.

The provided materials support verification of the reported overall event-based performance metrics, including true positives, false positives, false negatives, precision, recall, F1-score, and event-detection delay.

Participant identifiers are anonymized as P01–P10. Raw participant video recordings and personally identifiable information are not included.

These materials are provided to support independent verification of the reported overall evaluation results.
