# Normal-Driving Safety Evaluation

This directory contains the reproducibility materials used for the evaluation of system behavior during normal-driving sessions reported in IJIES Manuscript 20264753.

## Contents

This directory includes the anonymized system-output data from normal-driving sessions and the evaluation script used to assess false alarms and safety-critical activations during normal driving.

Participant identifiers are anonymized as P01–P10. Raw participant video recordings and personally identifiable information are not included.

These materials are provided to enable independent verification of the reported normal-driving safety evaluation results.
