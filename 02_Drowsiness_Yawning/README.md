# Drowsiness and Yawning Event Evaluation

This directory contains the reproducibility materials used for the event-based evaluation of driver drowsiness and yawning detection reported in IJIES Manuscript 20264753.

## Contents

This directory includes the anonymized system-output data, manually annotated ground-truth events, and the evaluation script used to reproduce the reported drowsiness and yawning event-level performance results.

Participant identifiers are anonymized as P01–P10. Raw participant video recordings and personally identifiable information are not included.

These materials are provided to enable independent verification of the reported drowsiness and yawning event-level results.
