# Simulated Medical-Emergency Event Evaluation

This directory contains the reproducibility materials used for the event-based evaluation of simulated medical-emergency detection reported in IJIES Manuscript 20264753.

## Contents

This directory includes the anonymized system-output data, manually annotated ground-truth events, and the evaluation script used to reproduce the reported simulated medical-emergency event-level performance results.

Participant identifiers are anonymized as P01–P10. Raw participant video recordings and personally identifiable information are not included.

All medical-emergency events in this evaluation were simulated experimental scenarios and should not be interpreted as clinically diagnosed or naturally occurring medical emergencies.

These materials are provided to enable independent verification of the reported simulated medical-emergency event-level results.
