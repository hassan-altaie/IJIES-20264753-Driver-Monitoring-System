# Distraction Event Evaluation

This directory contains the reproducibility materials used for the event-based evaluation of driver-distraction detection reported in IJIES Manuscript 20264753.

## Contents

- `distraction_csv/` — anonymized system-output CSV files used for the distraction-event evaluation.
- `distraction_gt/` — anonymized manually annotated ground-truth distraction events.
- `distraction_event_evaluation_final.py` — Python script used to perform event-level matching and calculate the distraction-detection performance metrics.

Participant identifiers are anonymized as P01–P10. Raw participant video recordings and personally identifiable information are not included.

These materials are provided to enable independent verification of the reported distraction event-level results.
